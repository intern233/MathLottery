# 对合排列上的四种网格模式等分布

本例给出 Fang–Fu–Kitaev–Li–Su–Sun 的 corrected Conjecture 1 的完整普通证明稿。独立 AI 审查结论为 **NO_ISSUES_FOUND**，新颖性评估为 **POTENTIALLY_NEW**；Lean 目前只完成部分形式化。

原题见《On mesh patterns of short length: Equidistribution and enumeration》2026-10-11 修订版，印刷页 17。[原论文](https://arxiv.org/abs/2606.14367v2)

对合排列是满足 π² = id 的排列。令 R = {(0,0),(1,1),(1,2),(2,1)}，R′ = {(2,2),(1,1),(1,0),(0,1)}。原题的四个模式依次为 (12,R)、(12,R′)、(21,R′)、(21,R)，出现条件采用严格空矩形定义。证明稿覆盖每个 n,k ≥ 0：四种模式在 n 阶对合排列中恰好出现 k 次的排列数相同。

证明将标记出现图中的星形分量旋转为路径分量，证明它与排列取逆相容且逐条保持边的转置关系；对转置不变的标记对象分别计算大小为 1、2 的轨道权重，再用生成多项式恢复所有出现次数。星形／路径方法已有文献先例，证明中明确致谢；新增论证集中于对合限制和轨道权重。
